# Mach3 G-Code Android App

Полнофункциональное мобильное приложение на Kotlin и Jetpack Compose для симуляции, редактирования и генерации G-кода для ЧПУ-станков (Mach3 / RS-274).

## 🚀 Открытие и запуск в Android Studio

### Требования
- **Android Studio**: Android Studio Ladybug (2024.2.1+) / Meerkat или новее
- **JDK**: Java 17 или Java 21 (рекомендуется встроенный в Android Studio JDK)
- **Android SDK**: Compile SDK 36, Min SDK 24 (Android 7.0+)

### Инструкция по запуску
1. Запустите **Android Studio**.
2. Выберите **File → Open...** (или *Open an Existing Project* на экране приветствия).
3. Укажите корневую папку данного проекта (`mach3-gcode-android`).
4. Дождитесь автоматической синхронизации **Gradle** (используется встроенный Gradle Wrapper `gradle-9.3.1`).
5. Выберите конфигурацию запуска `app` и нажмите зеленую кнопку **Run ▶** (Shift + F10) на эмуляторе или подключенном физическом Android-устройстве.

### Сборка через командную строку (Gradle Wrapper)
- **Сборка Debug APK**:
  ```bash
  # Linux / macOS:
  ./gradlew assembleDebug

  # Windows:
  gradlew.bat assembleDebug
  ```
- **Запуск тестов**:
  ```bash
  ./gradlew testDebugUnitTest
  ```
  Готовый APK-файл будет находиться в папке `app/build/outputs/apk/debug/app-debug.apk`.

## ✨ Основные возможности
1. **Разделенный адаптивный интерфейс**:
   - Верхняя половина: интерактивная 3D сцена обработки материала.
   - Нижняя половина: рабочая зона с вкладками (Псевдокод, G-код, Инструменты, Журнал, Остальное).
   - Интерактивный разделитель с возможностью перетаскивания (свободное изменение размера окон).
2. **Честная 3D симуляция фрезерования**:
   - Карта высот (HeightMap) с субтрактивным вычитанием материала при движении фрезы.
   - Режимы отображения: Закрашенный (Solid), Сетка (Wireframe), Прозрачный (с ползунком прозрачности 15–100%).
   - Настройка детализации/размера ячейки сетки (0.5 мм – 5.0 мм).
   - Детекция опасных коллизий (ускоренное перемещение G0 ниже поверхности материала, врезание с выключенным шпинделем).
3. **Multi-touch 3D управление**:
   - Вращение 1 пальцем, панорамирование 2 пальцами, масштабирование pinch-to-zoom.
   - Быстрые проекции: XY (сверху), XZ (сбоку), 3D (изометрия) и сброс вида (Reset).
4. **Единое меню**:
   - Все настройки, открытие/сохранение проектов, импорт/экспорт G-кода, библиотека функций и справочник доступны под одной кнопкой «Меню».
