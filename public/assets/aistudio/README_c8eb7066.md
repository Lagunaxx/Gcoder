# mach3-gcode-editor

***
##  Описание
Программа предназначена для составления G-кода для ЧПУ фрезерных станков с протоколом MACH3.<br>
Для пуска выполните:
```Linux
./run.sh
```
```Windows
./run.bat
```

<br>
В программе предусмотрено создание псевдокода, который сразу конвертируется в G-код и визуализируется в симуляторе.<br>
В симуляторе можно посмотреть как движение врезы, так и результат на заготовке, в том числе по шагам.
По коду имеется краткая справка сразу в выборе команд.<br>
Можно редактировать список инструментов (пока только прямые фрезы указанного диаметра),<br>
Итоговый G-код и псевдокод можно экспортировать в файлы.
Частично проверяются коллизии.

# Ограничения
Ввиду отсутствия достаточного времени код программы пишется целиком с помощью ИИ.<br>
Ввиду использования ИИ возможны ошибки.<br>
18.10.2026: На данный момент окно генерации модели не отстегивается нормально (падает с Segmentation Fault)
